# 本地双记忆契约

首次启动运行：

```bash
python3 <skill-root>/scripts/local_memory.py --directory .fanhan-job-agent
```

命令幂等创建两个文件，不覆盖已有内容。

## 用户求职记忆

文件：`.fanhan-job-agent/用户求职记忆.md`

- 只保存候选人明确确认的目标岗位、地点、办公方式、工作类型、到岗时间、公司偏好、排除项和渠道偏好。
- 与 `profile.json` 的硬限制保持同步；出现冲突时先请候选人确认，再同时更新两处。
- `职业经历.md` 继续保存职业事实和长期职业资产，不能被本文件替代。

## Agent 平台执行记忆

文件：`.fanhan-job-agent/Agent平台执行记忆.md`

- 只保存平台、操作、故障现象、已确认原因、解决办法、验证结果和适用条件。
- 尝试平台前先读同平台记录，避免重复走已知失败路径。
- 每次真实失败、恢复或平台行为变化后追加一条带日期的记录；原因未确认时明确写“未确认”，解决办法未验证时明确写“未验证”。
- 禁止写入候选人姓名、联系方式、简历正文、申请表答案、Cookie、Token、验证码或登录凭据。

两个文件不能互相代替，也不能上传到 Git、工作台、招聘网站或飞书群。
