让你的 Agent 更了解你

Agent 在帮你找工作的过程中越来越了解你，个人信息被沉淀在档案里，有了更多上下文背景。

  1. 01

    询问你的经历，建立个人档案和 Agent 档案

  2. 02

    你确认内容。没有你点头，不会写进档案。

  3. 03

    之后每次找岗位、改简历，都用这份越来越完整的上下文。
