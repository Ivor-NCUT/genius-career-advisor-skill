# 外部招聘网站可行性探测

本文件对应 GitHub Issue #25，只回答 V1 应先验证哪一个外部投递站点。探测日期为 2026-08-17；未使用真实候选人材料，未登录、未上传、未提交，也未尝试绕过验证码。

## 结论

首个直接投递候选选 **Bonjour**：它在同一站点提供公开岗位详情、登录检查、CV/作品集上传、岗位问题和最终“投递信号”动作，最接近 V1 要验证的单岗位闭环。

**Watcha** 保留为第二顺位：它有公开岗位接口、站内申请与 PDF 上传，但申请接口明确存在登录和验证码接管分支，首次投递适配变量更多。岗位发现本身不应再依赖 SPA 页面标题。

**JobRadar** 只作为岗位发现源：免费层公开配置把“详细 JD、投递入口”列为 Pro 能力，实际申请还可能跳到不同来源网站。它不能代表一个稳定的单站投递适配器。

## 探测结果

| 来源 | 公开岗位读取 | 站内申请 | 文件上传 | 人工接管 | V1 决策 |
|---|---|---|---|---|---|
| Bonjour | 有；详情页直接包含 JD 与岗位问题 | 有；最终动作是“投递信号” | CV 必须为 PDF、最大 10MB；作品集可选或按岗位要求 | 未登录时先进入登录；最终动作前必须停下确认 | 第一候选 |
| Watcha | 有；公开接口提供团队和岗位 | 有；提交到站内申请接口 | PDF 简历必填，作品集按岗位开放 | 登录必需；接口可能返回验证码接管 | 第二顺位 |
| JobRadar | 免费基础预览；完整搜索需登录/会员 | 不是统一站内闭环 | 取决于最终来源站 | 详细 JD 和投递入口受账号/付费层影响，且后续页面不统一 | 仅作受限发现源 |

## Watcha 可复现读取链路

2026-08-18 复测确认：

1. 查岗路由仍是 `https://watcha.cn/study/jobs`，前端路由声明包含 `/jobs`、团队页和岗位详情页。
2. 初始 HTML 壳的标题和 canonical 显示“AI 产品经理共学营”，因此 SEO 元数据不是岗位是否存在的证据。
3. 岗位页前端调用公开接口 `GET https://watcha.cn/jobs-api/v1/public/teams`，无需登录即可返回团队和岗位 JSON。
4. 本次接口实测返回 `totalTeams=21`、`totalJobs=47`。数量只作为当次探测证据，不硬编码为产品假设。
5. 岗位详情路由由团队 slug 与岗位 pathSlug 组成：`https://watcha.cn/study/jobs/<teamSlug>/<jobSlug>`。

V1 因此直接读取公开接口；接口失败时把 Watcha 标记为 `unavailable` 并继续其他来源，不再让浏览器反复加载查岗页。不能因为页面标题变化而把 Watcha 标记为无结果。

## Bonjour 可复现链路

本次选中的公开岗位详情：

`https://bonjour.bio/jobs-mapping/jobs/7109df69-b758-482b-be81-e9e60d2da79b`

只读探测确认的页面链路：

1. 公开详情页显示“我要投递”。
2. 申请路由先验证登录；未登录时打开登录流程。
3. 登录后可选择或上传 CV、作品集及作品链接，并填写岗位自定义问题。
4. 表单完整后，“投递信号”按钮才可用；该动作调用实际提交。
5. V1 必须在第 4 步点击前展示岗位、目标站点、文件名、字段类别和最终动作；用户本人点击最终按钮即构成本岗位的新确认。

## 侧边栏验证状态

2026-08-17 复测已在 Codex 内置侧边栏打开上述岗位，页面显示真格基金“内容实习生（音、视频向）”和“我要投递”按钮；点击后同一标签页进入：

`https://bonjour.bio/jobs-mapping/jobs/7109df69-b758-482b-be81-e9e60d2da79b/apply`

因此“侧边栏不能访问 Bonjour”不再是岗位发现阻塞。统一搜索脚本直接解析公开职位页随 HTML 返回的岗位数据；右侧栏只在用户选岗后打开详情与 `/apply`。申请页交互偶发超时只影响当前申请，不再导致 Bonjour 整个来源被标记不可用，也不得为绕过接管改用系统默认浏览器。

## 统一读取结论（2026-08-18）

`fanhan-job-agent/internal/external-jobs/scripts/external_jobs.py` 已成为三个外部来源的统一入口：

- Bonjour：公开职位页数据，在线验收读到 163 个岗位；查询“AI 产品经理”命中 8 个。
- Watcha：公开 feed，在线验收读到 47 个岗位；同一查询命中 5 个。
- JobRadar：免费层只提供基础预览，完整岗位与投递入口受登录/会员限制。V1 返回 `membership_required`，不把限制误报为浏览器超时，也不直接访问后台数据库绕过付费墙。

单一来源读取失败时只记录该来源 `unavailable`，另外两个来源继续返回。浏览器只在用户明确选岗后用于详情、登录和申请。

## 下一步验收

下一步只用一名已同意的真实测试者和一份可投递 PDF，从当前 `/apply` 标签页完成一次预演：

- 页面与岗位可读取；
- 登录时暂停并由用户接管；
- 上传个人数据前单独确认；
- 表单可以填写并恢复；
- “投递信号”前生成确认指纹并暂停；
- 用户拒绝时绝不提交；
- 只有用户针对当前岗位明确同意并本人点击，才发生单次提交；
- 成功证据不明确时记为 `submission_outcome_unknown`，不自动重试。
